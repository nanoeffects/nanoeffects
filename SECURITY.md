# Security policy

## Report a vulnerability

Please report it privately through [GitHub security advisories](https://github.com/nanoeffects/nanoeffects/security/advisories/new). Do not open a public issue.

Include the version, what an attacker can do, and the smallest code that shows it. I will answer as soon as I can.

## Supported versions

Fixes go into the latest release. See [Stability](docs/stability.md) for what each version promises.
