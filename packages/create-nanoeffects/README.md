# create-nanoeffects

Start a project with [nanoeffects](https://github.com/nanoeffects/nanoeffects).

```bash
npm create nanoeffects@latest my-app
```

Pick a template with `--template`: `vanilla` (Vite, a bus and `latest`) or `react` (Vite, `useEmitter` and `usePolicy`).

```bash
npm create nanoeffects@latest my-app -- --template react
```

[Docs](https://github.com/nanoeffects/nanoeffects/blob/main/docs/starter.md)
