# Документация

Читайте документацию с уровня вашего проекта и останавливайтесь, когда в нём есть всё нужное. Каждый уровень добавляет одну идею. Вверху страницы указано, для какого она уровня и что прочитать до неё.

Вы здесь впервые? Сделайте три вещи по порядку:

1. **Решите.** Прочитайте [README](../../README.md) (две минуты): для чего библиотека, как её установить, первый рабочий пример. [Зачем нужна nanoeffects](motivation.md) подскажет, когда она не нужна.
2. **Начните.** Запустите первый пример или создайте проект командой `npm create nanoeffects@latest my-app` ([Проект из шаблона](starter.md)).
3. **Поднимайтесь.** Идите по [Руководству](guide.md) шаг за шагом или найдите свой случай в [Рецептах](recipes.md).

## Лестница от A до F

| Уровень | Ваш проект | Можно остановиться, когда | Читать |
| ------- | ---------- | ------------------------- | ------ |
| **A** | Небольшое приложение, виджет или прототип, гонки редки | Событий и обработчиков хватает | [Руководство](guide.md#1-создайте-шину), шаги 1 и 2 |
| **B** | SPA с async UI: поиск, отправка, уход со страницы | Новый запрос должен заменять старый | [Политики](policies.md), [Руководство](guide.md#3-прерывайте-предыдущий-запуск-через-latest), шаги 3 и 4 |
| **C** | Ненадёжная сеть или длинный сценарий | Повторы, таймауты и ожидание закрыты | [Эффекты](effects.md), [Руководство](guide.md#5-добавьте-retry-и-timeout), шаги 5 и 6 |
| **D** | Доменная логика, которая должна жить вне UI | Фичи — это действия и модули, а не компоненты | [Действия, задачи и модули](actions.md), [Руководство](guide.md#7-называйте-события-тремя-способами), шаги 7–9 |
| **E** | Готовое приложение на Redux, Zustand, MobX или Pinia, либо библиотека данных | Шина ведёт async-работу рядом с вашим стором | [Сторы](stores.md), [Библиотеки запросов](query-libraries.md) |
| **F** | Платформа, SDK или долгоживущее приложение | Видно, что выполнилось, модули перезагружаются, можно опираться на правила | [Трассировка](tracing.md), [Горячая перезагрузка](hmr.md), [Семантика](semantics.md), [Стабильность](stability.md) |

Небольшому приложению уровни B и выше не нужны. Поднимайтесь, когда появится первая проблема этого уровня, а не раньше.

## Начните с трёх импортов

Большинству приложений нужны только они. Всё остальное необязательно: читайте, когда понадобится.

| Импорт | Что даёт |
| ------ | -------- |
| `nanoeffects` | `createBus`: `on`, `emit`, `ctx` |
| `nanoeffects/policies` | `latest`, `debounce`, ... против гонок в async UI |
| `nanoeffects/effects` | `retry`, `timeout`, `poll`, ... для ненадёжной сети |

Остальные точки входа и плагины: [Точки входа пакета](package.md) и [Плагины](plugins.md#выберите-плагин-по-задаче).

Код каждого шага руководства: [`examples/guide.ts`](../../examples/guide.ts) (проверяется типами и тестами).

## Перейти по потребности

Для проблемы начните с [Рецептов](recipes.md). Для формы проекта:

| Форма проекта | Первая страница |
| ------------- | --------------- |
| Небольшое приложение / виджет (гонки редки) | [Руководство § Создайте шину](guide.md#1-создайте-шину) |
| SPA с async UI | [Политики](policies.md), [Руководство § latest](guide.md#3-прерывайте-предыдущий-запуск-через-latest) |
| Ненадёжная сеть / длинные сценарии | [Эффекты](effects.md): один помощник на задачу, остальное как справочник |
| Доменная логика вне UI | [Действия, обработчики, модули](actions.md) |
| Уже есть Redux / Zustand / MobX / Pinia | [Сторы](stores.md) |
| Сервер на Node (Fastify), работа которого должна прекращаться, когда клиент ушёл | [Остановка работы на сервере](server.md) |
| Форма на React с async-проверками | [Форма регистрации на React](react.md) |
| Виджет на сайте, который слушает только пока открыт | [Виджет чата](chat-widget.md) |
| Приложение на Vue | [nanoeffects в приложении на Vue](vue.md) |
| Приложение на Svelte | [nanoeffects в приложении на Svelte](svelte.md) |
| Старые ответы затирают новые | [Отмена устаревших запросов](cancel-stale-requests.md) |
| Ввод с debounce, который должен ещё и отменять старый запрос | [Debounce и отмена](debounce-and-abort.md) |
| Второй клик отправляет второй запрос | [Защита от двойной отправки](prevent-double-submit.md) |
| Используете mitt, nanoevents или EventEmitter | [Переход с mitt](migrating-from-mitt.md) |
| Переходите с redux-saga | [Переход с redux-saga](migrating-from-saga.md) |
