# Документация

1. Прочитайте [Зачем нужна nanoeffects](motivation.md): для чего библиотека и когда она не нужна.
2. Установите пакет (`npm install nanoeffects`) и пройдите [Руководство](guide.md#1-создайте-шину). Или создайте проект командой `npm create nanoeffects@latest my-app` ([Проект из шаблона](starter.md)).
3. Свою проблему ищите в [Рецептах](recipes.md).

## Виды проектов

| Уровень | Проект | Читать |
| ------- | ------ | ------ |
| **A** | Небольшое приложение, виджет или прототип | [Руководство](guide.md#1-создайте-шину), шаги 1 и 2 |
| **B** | SPA с async UI: поиск, отправка, уход со страницы | [Политики](policies.md), [Руководство](guide.md#3-прерывайте-предыдущий-запуск-через-latest), шаги 3 и 4 |
| **C** | Ненадёжная сеть или длинный сценарий | [Эффекты](effects.md), [Руководство](guide.md#5-добавьте-retry-и-timeout), шаги 5 и 6 |
| **D** | Доменная логика вне UI | [Actions, jobs и модули](actions.md), [Руководство](guide.md#7-называйте-события-тремя-способами), шаги 7–9 |
| **E** | Готовое приложение на Redux, Zustand, MobX или Pinia, либо библиотека данных | [Сторы](stores.md), [Библиотеки запросов](query-libraries.md) |
| **F** | Платформа, SDK или долгоживущее приложение | [Трассировка](tracing.md), [Hot reload](hmr.md), [Семантика](semantics.md), [Стабильность](stability.md) |

## Основные импорты

| Импорт | Что даёт |
| ------ | -------- |
| `nanoeffects` | `createBus`: `on`, `emit`, `ctx` |
| `nanoeffects/policies` | `latest`, `debounce`, ... против гонок в async UI |
| `nanoeffects/effects` | `retry`, `timeout`, `poll`, ... для ненадёжной сети |

Подробнее: [Точки входа пакета](package.md) и [Плагины](plugins.md#выберите-плагин-по-задаче).
