# Ошибки и события без слушателей

> **Уровень B.** Сначала прочитайте: [Руководство](guide.md#1-создайте-шину), шаги 1 и 2.

Значения по умолчанию подходят небольшой шине. Задайте их, когда нужны изоляция или предупреждения об опечатках.

## Изолируйте упавшие обработчики

`emit` — обычный цикл по обработчикам (как в nanoevents). Если обработчик выбросил ошибку, остальные обработчики пропускаются, а ошибка доходит до вызывающего `emit`. Отклонённый промис async-обработчика остаётся необработанным.

Передайте `onError`, чтобы вместо этого изолировать обработчики. Тогда выполняется каждый обработчик. Выброшенные ошибки и отклонения async-обработчиков (в том числе обёрнутых в `latest`, `debounce` и подобные) попадают в `onError`. `onError`, который сам выбрасывает ошибку, логируется в `console.error`.

```js
import { createBus } from "nanoeffects";

// createBus — onError изолирует упавшие обработчики, чтобы остальные всё равно выполнились
const bus = createBus({
  onError: (error, { type, payload }) => {
    report(error, type, payload);
  },
});
```

## Предупреждайте, когда никто не слушает

Опечатка в имени события (`emit("serch")`) ничего не делает и ничего не говорит. `onUnhandled` срабатывает, когда событие отправлено, а никто не слушает (слушатель любого события, `"*"`, считается). Он не вызывается для действия, у которого есть обработчик для запуска. Действие без обработчика — просто событие, поэтому для него он вызывается.

Используйте его как предупреждение при разработке (`import.meta.env.DEV` — флаг Vite; в другом сборщике используйте свою проверку):

```js
import { createBus } from "nanoeffects";

const bus = createBus({
  onUnhandled: import.meta.env.DEV
    ? ({ type }) => console.warn(`Nobody listens to "${type}"`)
    : void 0,
});
```
