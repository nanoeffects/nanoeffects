# Ошибки и события без подписчиков

> **Уровень B.** Сначала прочитайте: [Руководство](guide.md#1-создайте-шину), шаги 1 и 2.

Небольшой шине хватает значений по умолчанию. Настройте обработку, когда нужна изоляция обработчиков или предупреждения об опечатках.

## Изолируйте упавшие обработчики

`emit` — обычный цикл по обработчикам (как в nanoevents). Если обработчик выбросил ошибку, остальные обработчики пропускаются, а ошибка доходит до вызывающего `emit`. Отклонённый промис async-обработчика остаётся необработанным.

Передайте `onError`, чтобы изолировать обработчики. Тогда выполняется каждый обработчик, а выброшенные ошибки и отклонения async-обработчиков (в том числе обёрнутых в `latest`, `debounce` и подобные) попадают в `onError`. Если сам `onError` выбросит ошибку, она попадёт в `console.error`.

```js
import { createBus } from "nanoeffects";

// createBus — onError изолирует упавшие обработчики, чтобы остальные всё равно выполнились
const bus = createBus({
  onError: (error, { type, payload }) => {
    report(error, type, payload);
  },
});
```

## Предупреждайте, когда никто не слушает

Опечатка в имени события (`emit("serch")`) ничего не делает и молчит. `onUnhandled` срабатывает, когда событие отправлено, а подписчиков нет (подписка на любое событие, `"*"`, считается). Для action с обработчиком он не вызывается. Action без обработчика — просто событие, поэтому для него вызывается.

Включайте предупреждение при разработке (`import.meta.env.DEV` — флаг Vite; в другом сборщике подставьте свою проверку):

```js
import { createBus } from "nanoeffects";

const bus = createBus({
  onUnhandled: import.meta.env.DEV
    ? ({ type }) => console.warn(`Nobody listens to "${type}"`)
    : void 0,
});
```
